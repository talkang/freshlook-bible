# 새번역 말씀노트 — 내 TXT로 읽는 한국어 성경 PWA

가지고 있는 성경 TXT 파일을 불러와 여백성경(문학적 조판) 방식으로 읽는 웹앱(PWA)입니다.
대화·시·편지·칙령을 본문 구조 그대로 조판하고, 인물·때·장소를 8가지 색으로 표시하며,
다크(검정)와 화이트(흰 종이) 테마를 오갑니다. 홈 화면에 추가하면 오프라인에서도 열립니다.

**라이브 주소: <https://talkang.github.io/freshlook-bible/>**

> 주소의 `freshlook-bible` 은 저장소 이름입니다. 앱 이름은 **새번역 말씀노트**이며,
> 주소를 바꾸면 이미 공유한 링크가 끊기므로 저장소 이름은 그대로 둡니다.

> ### 이 저장소에는 성경 본문이 들어 있지 않습니다
> 앱 껍데기(HTML·CSS·JS·아이콘)만 공개되어 있습니다.
> 본문은 방문자가 각자 가진 TXT 파일을 앱에서 직접 불러오고, 그 파일은
> **그 사람의 브라우저 저장소(IndexedDB)에만** 남습니다. 서버로 전송되지 않습니다.
> 불러온 본문의 저작권은 해당 권리자에게 있습니다.

---

## 쓰는 법

1. <https://talkang.github.io/freshlook-bible/> 를 엽니다. (휴대폰 크롬·사파리, PC 브라우저 모두)
2. 첫 화면의 **📄 내 새번역 TXT 파일 불러오기** 를 누르고 성경 TXT 파일을 고릅니다.
   파일은 브라우저 안에서만 해석되어 기기에 저장됩니다. (예: 66권 · 1,189장 · 31,102절이 10~20초에 들어옵니다)
3. 이후로는 앱을 열면 마지막에 읽던 곳에서 바로 이어집니다.
   크롬 **⋮ → 홈 화면에 추가**(또는 읽기 설정 → 홈 화면에 추가)로 앱처럼 설치할 수 있고,
   한 번 불러온 본문은 인터넷 없이도 열립니다.
4. 다른 기기에서 쓰려면 그 기기에서 같은 TXT 파일을 한 번 더 불러오면 됩니다.
   불러온 본문을 지우려면 **읽기 설정 → 불러온 본문 지우기**.

### 지원하는 TXT 형식

장·절 머리말이 있는 TXT입니다. 아래 형태의 줄을 읽습니다.

```
01 0:0 창세기,창,50
01 1:1 ○ 한처음에 하느님께서 하늘과 땅을 창조하셨다.
01 1:2 ○ …
```

(책 머리말 `번호 0:0 이름,약어,장수`, 절 `책번호 장:절 본문` — 대한성서공회 TXT 내보내기 형식과 같습니다.)

## 기능

| 영역 | 내용 |
|---|---|
| 조판 | 대화 들여쓰기 · 시 행 나누기 · 편지/칙령 박스 · 성경 인용 박스 · 소제목 개요 막대 |
| 색상 코드 | 하나님 · 예수님 · 성령님 · 말하는 사람 · 듣는 대상 · 나이 · 기간 · 지명 (8색, 전체/핵심/흑백 3단계) |
| 테마 | 다크 ↔ 화이트, 선택은 기기에 저장 |
| 검색 | 66권 전체 검색, 결과를 누르면 그 절로 이동 |
| 읽기 설정 | 글자 크기 13~26px · 명조/고딕 · 행간 3단계 · 각주 칩 표시 |
| 출력 / PDF | 책별 여백성경 조판 — A4·B5·A5, 단면/양면, 필기 여백(무지·줄·점·모눈), 컬러/흑백 |
| 오프라인 | 서비스 워커가 셸을 캐시, 본문은 기기 저장소에서 읽음 |

색은 수작업 태깅이 아니라 **규칙 기반 한국어 처리**로 붙습니다. 지명은 내장 사전(약 130개)에 있는
이름만 잡고, 화자·청자는 “~이/가 … 말하였다” 같은 서술 패턴에서 추론합니다.
따라서 사전에 없는 지명이나 대명사로만 지칭된 인물에는 색이 붙지 않을 수 있습니다.

## 저장과 개인정보

- 본문·설정·읽던 위치는 모두 **브라우저 안**(IndexedDB / localStorage)에만 저장됩니다.
- 서버로 보내는 요청은 앱 파일(HTML·CSS·JS·아이콘)을 받는 것뿐이며, 분석·추적 도구가 없습니다.
- 저장 공간이 막힌 브라우저에서도 읽기는 되고, 기억만 되지 않습니다.

## 로컬에서 열기

`fetch()` 로 파일을 읽으므로 `file://` 더블클릭으로는 동작하지 않습니다. 폴더에서 간단한 서버를 띄우세요.

```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080
```

## 내장 본문과 함께 쓰기 (개인용)

서버에 본문 JSON을 함께 두면 앱이 자동으로 인식해 첫 화면 대신 본문을 바로 엽니다.

```
data/index.json          { "version":1, "books":[ {id,name,abbr,nc,vs,...}, … ] }
data/books/01.json … 66.json
```

이 저장소는 그 파일들을 **포함하지 않습니다**. 정당하게 가진 본문으로 직접 만들어 개인 서버나
비공개 저장소에서만 쓰세요. 공개 저장소에 올리면 본문이 그대로 배포됩니다.

```
assets/css/app.css         다크/화이트 테마 · 조판 스타일 (+ 시작 화면)
assets/css/print.css       여백성경 조판 · 인쇄 스타일
assets/js/app.js           라우팅 · 목차 · 검색 · 설정 · 불러오기 · 시작 화면
assets/js/render.js        대화/시/박스/개요 렌더러
assets/js/colorize.js      색상 코드 엔진 + 범례
assets/js/parser.js        브라우저용 TXT 파서
assets/js/print.js         여백성경 조판 · 인쇄/PDF
assets/icons/              아이콘 192/512/maskable, favicon
data/index.json            본문 없음 표시(books: []) — 앱이 시작 화면을 띄우는 신호
```

## 수정할 때

- 셸 파일을 바꾸면 `sw.js` 의 `VERSION` 을 올리세요. 캐시 우선 정책이라, 올리지 않으면
  방문자에게 이전 화면이 계속 보입니다.
- 모든 경로는 상대 경로(`./`)입니다. `https://<사용자>.github.io/<저장소>/` 같은 하위 경로에서도
  그대로 동작합니다.

## 저작권

- 이 저장소의 앱 코드와 아이콘만 공개되어 있으며, **성경 본문은 포함되어 있지 않습니다.**
- 표준새번역을 비롯한 성경 본문은 각 출판 권리자(표준새번역은 대한성서공회)의 저작물입니다.
  본문을 사용·복제·배포하려면 해당 권리자의 허락이 필요합니다.
- 이 앱은 본문을 배포하지 않고, 방문자가 자신의 기기에서 자신의 파일을 읽도록 돕습니다.
